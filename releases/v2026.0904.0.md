# v2026.0904.0 — September 4, 2026

## Desktop v0.3.0

### Mission Control: Pulse + Queue HUD

The Pulse view in Mission Control just got real. What was a cool physics demo is now a live command center.

**Queue Health HUD** (top-left overlay):
- Real-time queue stats: Todo / Active / Blocked / Done
- Stale issue alerts with pulsing red indicator (>48h threshold)
- Fleet health row: running / idle / error agent counts
- Collapsible to a compact badge

**Root node queue badge**:
- Shows total open issues as a number on the company root node
- Color shifts: green (<15), amber (15-30), red (>30)

**Agent node enhancements**:
- Running agents show their current issue ID as an accent chip
- Error agents get a red ring for instant visibility
- Issue focus is visually prominent below the tool name

**Sticky blooms**:
- Comment bloom lifetime extended from 4s to 8s
- Blooms stay visible long enough to read and click

**Quick Actions bar** (bottom center):
- "Stale" button shows count and dropdown of stale issue IDs
- "New Issue" button for quick navigation
- Stale issue items click through to the issue drawer

### Fleet Self-Healing

- **resetStaleErrorAgents**: auto-reset agents stuck in "error" whose last run succeeded
- **reapStaleExecutionLocks**: release issue execution locks held >2 hours
- **Routine circuit breaker**: auto-pause routines with >50 open spawned issues and zero completions
- Both sweeps run on heartbeat interval, idempotent, log to activity log

### produce_deliverable Tool

- New adapter tool for binary file deliverables (base64-encoded)
- Handles any file type, unlike write_output (text only)
- Full test coverage

### Stale Approval Sweep

- Proactive sweep before turn start clears stale pending approvals
- Prevents cloud agents from wedging with 409 errors


### Pulse Board: Dynamic Layout & Density-Aware Sizing

- Top-down org chart layout replaces the original radial design
- Stage width scales dynamically (up to 1200px) based on agent count at each depth level
- Node sizes, text, and labels shrink gracefully when many agents share a level
- Density factor: 1.0 (≤30 agents) / 0.9 (≤60) / 0.8 (60+) — cards always readable
- Physics bounds, repulsion, and spring rest lengths all adapt to density
- Stage height grows proportionally with width to maintain aspect ratio

### Time Tracking + Email Notifications

- Time entries with start/stop, agent auto-tracking, manual entry
- Timesheet views: by agent, by project, by issue, weekly
- Email notification system with preferences, queue, digest modes
- Email provider abstraction: SMTP, SendGrid, Resend, Mailgun
- Unsubscribe token system
