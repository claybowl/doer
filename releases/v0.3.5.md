# v0.3.5

> Released: 2026-10-22

## Fixes

- **Windows compatibility** — Fixed two Windows-specific issues:
  - **Git "Filename too long"** — Added `core.longpaths=true` to all git operations (memory history, portability, migration)
  - **memfs symlink EPERM** — fs-mount strategy now uses directory junctions on Windows (no admin or Developer Mode required), with fallback to directory symlink, then copy

- **Phase 3 Handoff Trail** — Delegation chain timeline on IssueDetail page. Read-only view showing how work moved between agents (checkout → delegation → comment → status change → run lifecycle). Full chain depth, live updates on 5s interval.

## Upgrade Guide

Standard `doerai` startup will apply any pending migrations automatically. The desktop app will auto-update to 0.3.5 on next launch.
