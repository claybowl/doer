# v2026.625.0

> Released: 2026-06-25

## Fixes

- **memfs symlink mount no longer blocked by empty workspace directories** — `agentWorkspaceService.ensure()` now accepts a `skipSubdirs` parameter and the heartbeat queries memfs bindings before workspace setup, so that directories managed by fs-mount bindings (e.g. `memory/`) are not created as plain directories that would block symlink creation. This resolves `"memfs mount skipped — target already exists and is not our symlink"` errors on heartbeat wake.

- **fs-mount strategy now replaces empty directories and gives actionable errors** — When the target path for an fs-mount symlink already exists as an empty directory, it is safely replaced with the symlink. When it exists as a non-empty directory, the error message now tells the user exactly which files to move and where, and suggests changing `mountAs` as an alternative. Wrong symlinks get a similar actionable message.

## Desktop

- Desktop version bumped to **0.1.9**. Binaries available for Mac (arm64), Windows (x64), and Linux (x64 AppImage).
