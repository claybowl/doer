# v0.3.4

> Released: 2026-10-22

## Critical Fixes

- **Bundled Letta Code CLI upgraded 0.28.17 → 0.34.20** — Fixes agent tool-call loss on desktop. The old bundled CLI lost tool calls in flight (heartbeat would spawn, model would run, but tool calls never executed, timing out after ~3 minutes). Verified: same agent conversation executes tools cleanly on 0.34.20. ([#6efd1215](https://github.com/claybowl/doer/issues/6efd1215))

- **letta-agent-sdk upgraded 0.2.7 → 0.8.50** — Resolves `adapter_failed: App-server resumeSession() does not yet support systemInfoRem` error on Letta Cloud sessions. The old SDK bundled an app-server that didn't recognize the `systemInfoRem` field Letta Cloud now sends.

- **letta-code upgraded 0.28.17 → 0.34.20** (transitive via leatta-agent-sdk) — Same fix as above, ensures tool execution works in spawned CLI sessions.

- **letta-client upgraded 1.10.3 → 1.12.1** (transitive) — Compatible with agent-sdk 0.8.x.

## Migration

- Removed deprecated `transport: "app-server"` from local client options (SDK 0.8+ no longer accepts this field; local backend always uses app-server protocol).

## Testing

- All adapter-letta-code tests pass (92 tests).
- Full typecheck clean across workspace.

## Upgrade Guide

Standard `doerai` startup will apply any pending migrations automatically. The desktop app will auto-update to 0.3.4 on next launch (or download from GitHub Releases).

If you have a worktree instance, run `doerai worktree:refresh` to pull the latest schema.
