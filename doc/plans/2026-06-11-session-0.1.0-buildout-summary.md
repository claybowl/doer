## The arc

Started with a banner; ended with a product. The session began as a cosmetic fix
(the dev server still said PAPERCLIP) and became the full execution of the
0.1.0 direction: make the DonDog → Chef → Alfie orchestration magic visible,

Governing design rule, held throughout: **users edit who an agent *is*; the
agent decides what to *do*.**

- Write path opened: new bindings default read-write on their own namespace;
  automatic Letta binding stays read-only.
- Visible org memory root `~/Doer/<org>/memory` (replaces hidden `.letta-memory`);
  new fs-mount agents auto-provision `agents/<slug>/` + AGENTS.md seed at hire.
- `memfsCapability` plumbed through every adapter + registry.
- UI: Memory section in agent config (Where/How/auto-skill note, create-default
  button), org root-path inline editing, **editable memory files** (browser +
  editor in the agent Memory tab), **git History view with session diffs**.
- Run-end auto-commit: every run snapshots what the agent wrote —
  "memory: <agent> — run <id>" appears in History with a diff.
